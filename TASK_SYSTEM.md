# INDIA SIMULATOR — TASK SYSTEM

Tasks use this lifecycle:

BACKLOG → READY → ACTIVE → VALIDATING → DONE

A task must contain:
- objective
- owner
- allowed scope
- dependencies
- acceptance criteria
- validation commands
