# INDIA SIMULATOR — TECHNICAL ARCHITECTURE

## Engine
Unreal Engine 5 is the intended game engine.

## Architecture boundaries
- Gameplay
- World
- NPC AI
- Missions
- Vehicles
- Economy
- UI
- Audio
- Save/Load
- Narrative/Data

## Engineering rules
1. Search before creating a new system.
2. Prefer data-driven systems.
3. Keep subsystem interfaces explicit.
4. Avoid unrelated refactors.
5. Every completed feature must be validated.
6. Do not claim success without a build/test result.
7. Optimize for maintainability and scalable world simulation.
