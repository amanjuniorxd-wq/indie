# INDIA SIMULATOR — GAME BIBLE

## Vision
Create a deeply simulated, story-driven open-world game set in a fictionalized India-inspired world. The game emphasizes character depth, persistent consequences, relationships, exploration, work, family, culture, economy, and emergent stories.

## Design principle
The world should feel alive even when the player is not looking at it. NPCs have schedules, relationships, goals, memories, and reactions.

## Current target
Vertical Slice 0.1: one compact neighborhood/district, one protagonist, persistent NPCs, one vehicle, interaction, dialogue, one complete mission, day/night, save/load, and automated validation.

## Rule
Do not attempt to build the entire open world before the vertical slice is playable and stable.
